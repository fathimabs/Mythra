# 📚🎬 Mythra

Mythra is a full-stack MERN application that helps users discover, organize, and manage their favorite movies and books in one place. The application provides a clean, responsive interface with secure authentication and an intuitive user experience.

🌐 **Live Demo:** https://mythra.netlify.app/

---

## ✨ Features

- 🔐 User Authentication (JWT)
- 👤 User Registration & Login
- 🎬 Browse Movies
- 📚 Browse Books
- 🔍 Search Functionality
- ❤️ Save Favorites
- 🖼️ Image Uploads with Cloudinary
- 📱 Responsive Design
- ⚡ REST API Integration
- 🎨 Modern UI built with Tailwind CSS

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/fathimabs/Mythra.git
```

Install dependencies

```bash
npm install
```

Run the frontend

```bash
npm run dev
```

Run the backend

```bash
npm start
```
